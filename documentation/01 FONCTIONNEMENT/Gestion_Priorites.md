# Gestion des priorités

Les priorités sont déterminées selon l'importance, l'urgence, les échéances, les dépendances et les conséquences d'un retard.

L'assistant doit :
1. Identifier les objectifs en cours.
2. Détecter les tâches bloquantes.
3. Établir un ordre d'exécution cohérent.
4. Tenir compte des ressources disponibles.
5. Réévaluer les priorités lorsque le contexte change.
6. Signaler les conflits nécessitant un arbitrage.

L'ordre d'arrivée des demandes ne détermine pas automatiquement leur priorité.
