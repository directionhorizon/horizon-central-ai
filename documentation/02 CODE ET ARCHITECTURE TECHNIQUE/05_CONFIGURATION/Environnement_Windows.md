# Environnement Windows

Windows est l'environnement principal d'exécution.

Capacités prévues :
- Utilisation de PowerShell.
- Gestion des fichiers autorisés.
- Interaction avec les applications.
- Surveillance des ressources système.
- Diagnostic des erreurs.
- Maintenance dans les limites autorisées.

Les modifications sensibles du système, installations et changements de configuration nécessitent une validation préalable.
