# Intégrations et API

Les intégrations permettent d'accéder aux applications, services et systèmes externes.

Principes :
- Privilégier les API officielles.
- Vérifier les permissions et les limites.
- Protéger les clés et identifiants.
- Gérer les erreurs et interruptions.
- Documenter chaque connexion.
- Prévoir une solution de remplacement lorsque cela est pertinent.

Aucun service externe ne devient obligatoire sans évaluation préalable.
