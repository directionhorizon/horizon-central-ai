# HORIZON LOCAL AI — TOKEN OPTIMIZATION

## Mission
Minimiser les dépenses en tokens et crédits API tout en privilégiant la livraison de fonctionnalités réellement opérationnelles.

## Règles obligatoires

1. Réutiliser les audits, rapports, inventaires et décisions déjà disponibles.
2. Ne jamais refaire une analyse déjà terminée sans justification.
3. Lire uniquement les fichiers nécessaires à la mission.
4. Privilégier les commandes locales, scripts et tests automatisés.
5. Éviter les longues explications et les sorties de terminal inutiles.
6. Regrouper les modifications cohérentes pour limiter les échanges.
7. Fournir des rapports courts : résultat, fichiers concernés, erreurs et prochaine action.
8. Choisir le modèle le moins coûteux capable de réaliser correctement la tâche.
9. Réserver les modèles plus puissants aux problèmes complexes d'architecture et de débogage.
10. Signaler les opérations susceptibles d'entraîner une forte consommation.
11. Ne jamais relancer inutilement une tâche terminée.
12. Ne jamais sacrifier la qualité, la sécurité ou les tests pour économiser des tokens.
13. Respecter strictement le budget API autorisé.
14. Ne jamais déclencher de recharge automatique ni modifier les limites financières sans autorisation.

## Priorité absolue
Produire du code fonctionnel, testé et vérifiable avec le minimum de consommation inutile.

## Mode de travail
Après validation d'une étape, passer directement à la suivante dans le périmètre autorisé, sans multiplier les demandes de confirmation.
